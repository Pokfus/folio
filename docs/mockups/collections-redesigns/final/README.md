# The composed Collections page (Oct 2026)

The Ledger (`../c-3-ledger.html`) with its decks / written / cards / learned columns replaced by the
Shelf's fill rows (`../c-1-shelf.html`): one bordered ledger per tab, a band per section, and inside it
each collection as a row whose colour fill is the share of it studied, with the mark, the deck and card
line, the written-of-planned reach, Try ten, add and expand. Your decks are a second ledger of the same
rows with the editor opening under the one being edited. The Studio's functions are all on this page;
`#studio` goes. `build.js` borrows the parent generator's data and pieces; edit it, not the page.
