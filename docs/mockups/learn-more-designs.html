Six treatments for “Learn more”

A link to the answer’s own Wikipedia article, placed below the Sources fold at the very foot of a card. Each mock-up is the end of card gr-010 (Throne Room at Knossos) in the default Folio theme. Design 2 was chosen and now carries the Wikipedia logo; the other five stay for the record.

Common to all six

  • The block renders only when a card carries a Wikipedia slug, and the article is the term in the answer itself, never a broader topic. The glossary already keys its terms on Wikipedia slugs, so most answers can be matched from existing data.
  • It is appended after the Sources fold in buildBack, outside the Background fold, and the link opens in a new tab like every citation, so following it never ends a study session.
  • Every colour is a theme token, so each design follows all of Folio’s themes and the night mode. A “W” set in the card’s serif stands for the destination; Wikipedia’s own logo is not used.
  • A Wikipedia article is not a source and is not counted in the Sources chip. The label says “Learn more”, which is what the link is for.
