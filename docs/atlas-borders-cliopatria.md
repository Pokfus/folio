  (https://raw.githubusercontent.com/Seshat-Global-History-Databank/cliopatria/main/LICENSE.md, HTTP 200), and the Zenodo
  metadata (`license: cc-by-4.0`) for both record 13363121 (v0.0.1) and the latest version record 20274630 (v0.2.0, 2026-05-16;
  creators listed on Zenodo: Ed Chalstrey, James Bennett; version DOI 10.5281/zenodo.20274630, concept DOI 10.5281/zenodo.13363120).
  Requires credit, a link to the licence, and an indication of changes. (`LICENSE`, `LICENCE`, `LICENSE.txt`, `CITATION.cff` → HTTP 404.)
- **Downloaded:** https://raw.githubusercontent.com/Seshat-Global-History-Databank/cliopatria/main/cliopatria.geojson.zip
  (HTTP 200, 44,231,317 bytes — byte-identical in size to the `v0.2.0` tag, so main = v0.2.0). README from the same raw path (HTTP 200).
  Zenodo API: https://zenodo.org/api/records/13363121 and `/versions/latest` (both HTTP 200; the Zenodo file itself is a 297 MB repo
  snapshot and was not needed).
- **Format:** the zip holds one file, `cliopatria_polities_only.geojson` (165.6 MB; internal `name` "cliopatria_polities_only_v012"),
  a GeoJSON FeatureCollection in CRS84 (EPSG:4326). 13,765 features = 13,380 `POLITY` + 385 `RELATION` rows; 1,633 distinct
  names. Properties: `Name, FromYear, ToYear, Area` (km², EPSG:6933), `Type, Wikipedia, Wikidata, SeshatID, Components, MemberOf`.
  Geometry: 6,531 Polygon / 7,234 MultiPolygon; vertices per row median 93, 90th percentile 596, max 6,789. Range 3400 BCE–2024 CE;
  one row per span over which the shape is constant (time steps are irregular: from 1 year to several centuries).
  Names in parentheses, e.g. `(Macedonian Empire)`, are composites (a polity plus its dependants; `Components` lists them) — excluded here.
- It is a **polity** dataset: no archaeological cultures, almost no tribes/peoples, and Greek poleis are one blob ("Greek City-States").

## Findings in one paragraph

Cliopatria is a strong source for states from c. 750 BCE on: Rome, Carthage, the Achaemenids, the Hellenistic kingdoms, the Chinese
Warring States, the steppe khaganates, the medieval kingdoms and every WWII belligerent resolve year by year, with typically
50–1,000 vertices per shape against Folio's ~10. It has nothing for the archaeological cultures (16 of the inventory's areas), the Italic
peoples other than the Etruscans, Sparta/Athens/Messenia as separate poleis, the Iberian, Gallic and Lusitanian peoples, the Pechenegs,
the Vyatichi, the Western Confederacy, and anything before 3400 BCE. historical-basemaps fills a few of those gaps (Cycladic, Minoan,
Yamnaya, Beaker, Únětice, Cimmerians, Sabines, Samnites, Sarmatians, Pechenegs) but only as one or two coarse snapshots each, under GPL-3.0.
